ili2c (Imd16Generator) does not write the documentation of enumeration elements to the IMD,
although IlisMeta16 allows it on EnumNode (MetaElement.Documentation).

- `EnumDocs_V1.imd` is the plain ili2c output of `EnumDocs_V1.ili`
- `EnumDocs_V1_EnumNodeDoc.imd` is a copy where the documentation of the enumeration elements
  from `EnumDocs_V1.ili` was added by hand to the EnumNode objects
